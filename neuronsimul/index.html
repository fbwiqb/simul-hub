📖 신경세포 막전위 시뮬레이터 사용법

🎯 프로그램 소개

신경세포 막전위 시뮬레이터는 신경세포에서 활동전위가 축삭을 따라 전도되는 과정을 시각적으로 관찰할 수 있는 교육용 프로그램입니다.

🎮 기본 사용법

1. 자극 지점 선택

  • 🎯 자극 지점: d₁(0cm)~d₄(6cm) 중 자극 위치를 선택합니다
  • d₁이나 d₄: 한 방향 전파 / d₂나 d₃: 양방향 전파

2. 전도 속도 설정

  • 기본값 2 cm/ms, 0.1 단위로 조절
  • 속도 변경 시 시간 슬라이더 범위가 자동 조정됩니다

3. 시간 조절 / 재생

  • ▶ 재생: 자동으로 시간이 흐르며 전파 관찰
  • 슬라이더를 직접 움직여 원하는 시간으로 이동

4. 데이터 캡처

  • 📸 캡처: 현재 시간의 막전위를 표에 고정
  • 여러 시점을 캡처하여 비교 분석 가능

5. 역치 / 자극 세기 (실무율)

  • 🚪 역치: 활동전위가 발생하는 막전위 기준값
  • 💥 자극 세기가 역치 이상이면 활동전위가 발생하고, 역치 미만이면 발생하지 않습니다
  • 일단 발생하면 자극이 아무리 세져도 파형(크기)은 항상 동일합니다 — 실무율(all-or-none)

6. 막전위 단계 표시 (색 + 글자 병기)

  • 휴지 휴지전위 (약 -70mV)
  • 탈분극 막전위 급상승 (Na⁺ 유입)
  • 재분극 막전위 하강 (K⁺ 유출)
  • 과분극 휴지전위 아래로 내려감
  • 회복 과분극 후 휴지전위로 복귀

각 단계는 색만이 아니라 그래프 정보의 단계 글자로도 함께 표시되어 색 구분이 어려워도 알 수 있습니다.

🔬 과학적 배경

자극이 역치를 넘으면 Na⁺ 통로가 열리며 막전위가 급격히 상승(탈분극)하고, K⁺ 통로가 열리며 다시 하강(재분극)합니다. 이 활동전위는 축삭을 따라 전파됩니다.

※ 본 시뮬레이션의 파형은 실제 이온 통로 동역학을 푸는 모델이 아니라, 교과서의 막전위 변화 단계를 단순화해 보여 주는 현상론적 근사 파형(교과서형 단계 모델)입니다. 활동전위 직후의 짧은 구간은 불응기여서 역방향으로는 다시 흥분이 일어나지 않습니다(역전파 차단).
