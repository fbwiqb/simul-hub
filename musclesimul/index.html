      📖 슬라이딩 필라멘트 이론

      🔬 기본 원리

      근육 수축 시 액틴(가는 필라멘트)이 마이오신(굵은 필라멘트) 사이로 미끄러져 들어가면서 근절(sarcomere)의 길이가 짧아집니다.

      🏗️ 주요 구조

      • Z선: 근절의 양 끝 경계
      • M선: 근절의 정중앙, 마이오신의 중심
      • A대: 마이오신 필라멘트가 있는 영역 (1.6 μm, 일정)
      • I대: 액틴만 있는 영역 (수축 시 감소)
      • H대: 마이오신만 있는 영역 (수축 시 감소)

      📐 수치 정보

      • 마이오신 길이: 1.6 μm (일정)
      • 액틴 길이: 1.0 μm (일정)
      • A대 = 마이오신 길이 = 1.6 μm (일정)
      • I대 = 근절 - A대 = 근절 - 1.6 μm
      • H대 = 근절 - 2 × 액틴 (= A대 - 겹치는 구간)
      • ½ I대 + ½ 겹치는 구간 = 액틴 길이 (항상 1.0)
      • 기준값 2.4 μm: 이완 상태(H대가 뚜렷이 보이는 안정 길이)를 변화량 비교의 기준으로 잡은 값입니다. 최대 장력이 나오는 최적 겹침 구간은 2.0~2.2 μm이며, 기준값(2.4)은 최적 길이와 다릅니다.

      💪 장력-길이 관계

      • 2.0~2.2 μm: 최대 장력 (100%) - 최적 겹침
      • 2.2~3.6 μm: 장력 감소 - 겹침 구간 감소
      • 3.6 μm 이상: 장력 0% - 겹침 없음
      • 2.0 μm 미만: 장력 감소 - 과도한 겹침으로 간섭 (슬라이더를 1.6 μm까지 내려 직접 확인)

      ⚠️ 활주설(슬라이딩 필라멘트) 오개념 주의

      액틴과 마이오신 필라멘트 자체의 길이는 수축할 때 변하지 않습니다. 필라멘트가 짧아지거나 늘어나는 것이 아니라, 액틴이 마이오신 사이로 미끄러져 들어가 겹침이 늘고 근절(Z선 사이 거리)·I대·H대가 짧아지는 것입니다. 따라서 A대(마이오신 길이) 1.6 μm와 액틴 1.0 μm는 항상 일정합니다.

      📊 수축 시 변화 요약

      • 근절 길이 ↓ (Z선 간 거리 감소)
      • I대 길이 ↓
      • H대 길이 ↓
      • A대 길이 = 일정
      • 액틴-마이오신 겹치는 구간 ↑

      ❓ 사용법

      🎮 기본 사용법

      1. 슬라이더 조작

      • 슬라이더를 좌우로 움직여 근절의 길이를 조절합니다 (1.6~3.6 μm)
      • 좌측: 과도한 수축 (1.6 μm, 과겹침 간섭) / 우측: 이완 (3.6 μm)
      • 2.0 μm 미만 구간에서 장력이 다시 감소하는 과도한 겹침 효과를 직접 확인할 수 있습니다

      2. 재생 기능

      • ▶ 재생: 자동으로 수축/이완 애니메이션
      • 속도 선택: 느림, 보통, 빠름

      3. 데이터 캡처

      • 📸 캡처: 현재 길이 데이터를 표에 기록
      • 📷 스크린샷: 현재 화면을 이미지로 저장

      4. 계산기

      • 드롭다운에서 두 값을 선택하고 연산자를 적용하여 관계식 검증
